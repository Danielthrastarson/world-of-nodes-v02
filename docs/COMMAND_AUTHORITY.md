# F13B — accepted office and scoped obligation

Owner decision: **office-based scoped obligation**, replacing the unresolved F13
proposal. This is an explicit new institution, not a forecast or arithmetic fix.
A sovereign has no universal command right over Persons. Historical F10/F12/F13A
artifacts remain unchanged; registered flags retain their prior institutions.
The [disclosed military clock correction](../research/command-chain/CLOCK_REGRESSION_REVIEW.md)
changes timing/hashes in one F13A scenario without changing final physical outcomes.

`Config.commands` enables this institution and requires F10 authority and F12
information. With it enabled, AppointSteward creates a local **offer**, not active
authority. The candidate separately accepts at physical contact with the living
appointing sovereign. Both retain the accepted office certificate. The ordinary
Person acceptance opportunity requires safe idle state (nutrition >=12h, fatigue
<18h), after existing survival/care/service opportunities. These provisional
acceptance thresholds are a bounded behavioral hypothesis, not a universal claim.
Experiment office acceptance is an explicit controlled voluntary act in both arms.
Legacy configurations retain historical F10 unilateral appointment semantics;
they do not thereby acquire scoped command duties.

Supported command: `CommissionCrossing { project, settlement }`, addressed to
one accepted steward office. A sovereign must personally know the project site
from local observation. A site description reveals neither current remote inputs
nor workers, completion, usefulness or route. Issuance creates an immutable
message in the issuer's own memory. A typed unsupported payload exists solely to
exercise rejection; it does not implement confiscation or any other new power.

Both orders and revocations are physically held information objects. F12's
living, capable, colocated communication boundary is shared. A controlled willing
carrier uses remembered routes and ordinary Person actions to a fixed rendezvous.
It cannot track the recipient, skip FIFO, create food or report death remotely.
No autonomous courier recruitment or Crown labor entitlement is claimed.

Recipient validation uses its accepted certificate, the actual received envelope,
own clock and previously received revocations. It does not query distant sovereign
health, globally issued withdrawals, material availability or remote office state.
Messages cannot be forged through this API. Authentication here means provenance
through trusted typed kernel endpoints; deception is outside the institution.
Receipt does not select an action or schedule an extra off-clock policy wake.

Common Person precedence: eating and bodily/dependent restrictions; critical food
acquisition; critical fatigue/recovery; existing indivisible gathering; eligible
received role undertaking; existing care, reproduction, service, delivery and
ordinary economic opportunities. A role duty with no known route or survival-safe
forecast pauses. It is not proof of true physical unreachability. Critical hunger
without a known source still pauses duty. Only its own pending queue application
is withdrawn; an underway edge remains atomic. Membership and other duties stay.
Typed candidate/action matching protects selected duty/delivery from the optional
barter stage; descriptive strings do not establish authority or obligation.

Office, belief, role obligation, atomic action and project have separate state.
`Completed` means the lawful local commission exists, **not** that a crossing does.
Construction remains the original public project with voluntary material/labor.
Missing wood or workers is a downstream realization failure, not steward refusal.
`Failed` covers inability discovered through local execution or death after receipt;
`Paused` preserves recoverable constraints; `Expired` uses the known deadline.
Deliberate refusal is available as a typed personal institutional choice with an
explicit reason and no punishment. The refusal witness is controlled, not a claim
that an autonomous general dissent policy or social psychology has been validated.

Revocation has no recipient effect until receipt. Early withdrawal receipt survives
later delivery of the original. Ending a pending obligation clears only its
attributed continuation. It neither reverses completed travel nor repeals an
already completed, independent public commission. Project repeal would need its
own explicit semantics; no such power is inferred.

Production state is personal sparse memory plus immutable message IDs. Observer
journals are excluded from policy and state hashing. No all-Person cross-product,
remote mailbox polling, obedience scalar, compulsory worker or household pooling
is introduced. The kernel remains headless.
