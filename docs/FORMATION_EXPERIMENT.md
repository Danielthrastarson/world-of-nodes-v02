# F11B — registered organization/movement experiment

Owner accepts F11A mechanism scope. Its protective-benefit gate remains open for F11C. F11B does not add combat.

## Representation

An opt-in organizational Unit holds references to existing Persons. Enlisted roster entries are distinct from actual muster arrivals, current active service, movement, separation, recovery, release and death. Roster history is retained. Actual counts are research/kernel truth, not information delivered to NPCs. No army inventory or new body, physiology, property right, military road or priority admission.

The spatial kernel has nodes and fractional progress along edges, not two-dimensional battlefield positions or width. Desired formation is graph gathering at an anchor. Line/column/front geometry is deferred; no associated bonuses.

## Command and commitment

A research-issued Move(target) object is copied only to assembled, actively serving Persons physically colocated at the issue node. Receipt gives a target, not hidden routes/resources or remote membership state. Unassembled/absent people receive nothing; no automatic broadcast to later arrivals. Later local orders do not update absent members. Each recipient uses their own remembered graph and the corrected route forecast. Unknown routes and predicted fatal traversal cause explicit waiting/pausing, never omniscient path selection.

A received movement undertaking is eligible after existing eating, critical survival, sleep, care and reproductive priorities and before ordinary civilian opportunities. These interruptions retain membership/order; the new rule is explicit resumable organizational commitment, not a separate SoldierAI. Critically hungry members pause even if no source is known. Existing service expiry and explicit voluntary withdrawal remain real: no order extends service. Released/dead members remain roster history but do not count as active strength. Atomic travel continues to its endpoint if service expires mid-edge. No snaps or catch-up speed.

## Fixtures and controls

Thirty paired seeds0–29 per case,24h after order. Main comparison: identical voluntary muster, Move versus no Move. Cases: short route; two-edge known route; unknown route; civilian congestion; long march; food-constrained command state; fatigue-constrained command state; capacity-one bottleneck; path effect enabled/disabled; partial muster; late arrival; care conflict; shared route with civilian work; existing lawful cart. Paths additionally compare movement with the physical path effect toggled. Crossings use the existing construction mechanics in a controlled preparation fixture/test, never free capacity for soldiers.

Ordinary fixtures use four adults,18h initial nutrition,6 owned food quanta each,12h voluntary terms and60h request expiry. These are F11B experimental initial parameters, not edits to F11A's preserved2h terms. Muster and target are distinct; a single order is issued at1h. Available food remains physical/personal. Stress-at-command fixtures explicitly set one member's hunger/fatigue (or observed dependent need) as counterfactual initial conditions for the movement test; they do not claim those conditions emerged from recruitment. Off/on receive identical interventions. No such mutations occur after the initial movement state. Prior route observations in the two-edge fixture are explicitly seeded timestamped memories with no remote resource updates. The unknown-route control omits them.

Civilian traffic is autonomous. Its requests are never known until a legitimate visit to the posting. Where isolation needs a fixed non-recruiting civilian cohort, people start with an existing communal job, which the current service gate refuses; no new military quota. Record any later civilian enlistment rather than hiding it.

## Metrics and validation

Roster versus active counts, notices/receipt, departures and arrivals during service versus post-service endpoint arrival, individual travel/queues/food/starvation/fatigue, civilian cost relative to paired control, pauses by reason, household care and work, arrival-time spread, maximal colocated fraction and fraction at objective. Position/graph-separation metrics are observations only; no cohesion multiplier. Include fractional edge progress in state/traces and report node cohesion as zero while everyone is in transit, rather than pretending edge positions are nodes.

Static tests: locality; partial/late/reissued commands; atomic travel; service expiry; kin/property/biology persistence; pause/resume; death history; FIFO with civilians; existing path/crossing/cart laws; deterministic decisions and old artifacts. Old F11A/B0–B3 outputs must remain exact with organization disabled. No outcome is required to be efficient. Gate F11B requires explanatory evidence for organizational control through existing physical Persons, not successful protection. If passed, begin F11C by defining its smallest concrete threat/control before implementing combat.
