# F12: embodied transport of dated evidence

Optional configuration `information=true` adds personal report memory to the common Person capability selector. The historical default remains false. This implements a controlled communication mechanism, not an autonomous profession or a government messaging service.

A report is an immutable `(id, author, NodeView)` from a living capable Person's actual current local observation. Carriers hold independent copies; receipt records immediate sender and receipt time separately from original author and observation time. The original local-view boundary, including one-bank queue knowledge, is unchanged. A report never refreshes itself from the remote world.

`capture_report`, `receive_report` and `begin_report_delivery` validate physical identity/location and held evidence. Handoff requires node co-location. Oral copying follows existing instantaneous local institutional actions; transport consumes ordinary time and physiology. There is no material paper, broadcast, delivery acknowledgement or remote recipient lookup.

Truthful report acceptance is an explicit experimental assumption. A newer report may update spatial beliefs. `reported_nodes` identifies the active imported belief and points to its personal receipt. Equal/older observations cannot replace newer evidence. Direct local observation removes that marker while preserving the historical report. A kernel audit requires the active marked belief to equal the original report payload. B2 trust has not been redefined as source credibility.

An undertaking names a held report, recipient and fixed rendezvous. The existing Person selector preserves immediate food, recovery, care, reproduction, combat and service priorities. The selected delivery purpose precedes new economic work; a narrow arbitration guard prevents the later barter selector from overwriting it. Unknown route, critical hunger or predicted death can pause; observed recipient absence at rendezvous cancels. No remote tracking or compulsory courier assignment exists. Experimental purpose injection is labelled initial motivation, not an autonomous decision to become a messenger.

Receipt changes evidence without interrupting the recipient's previously selected action. The next ordinary policy opportunity may use it. An arbitrary caller `advance_to` partition cannot accelerate deliberation. At a shared timestamp the runtime may have selected a decision before a handoff was executed; event ordering alone is not evidence that the decision used the new report. Matched decision controls establish that causal effect explicitly.

Birth creates empty report memory, not inherited knowledge. Death retains historical records and cancels an undertaking; it neither delivers reports nor notifies relatives. This first report type does not update B2 death knowledge, offices, military rosters, private market beliefs or authority rights.

The research journal is observational and excluded from authoritative state hashing. Removing it does not change execution. Personal evidence and undertakings are authoritative and included when the option is enabled. Disabled old configurations retain the original hash path. Config debug text includes the added optional field; it is not a physical-state regression.

Scaling remains bounded only by the current experiment duration. Storage is sparse in actual reports/receipts, with no all-person exchange loop. Report retention has no forgetting policy yet. Existing global observation/combat scans and minute-level policy updates remain separate scaling debt. Small fixtures establish semantics, not large-population performance.
