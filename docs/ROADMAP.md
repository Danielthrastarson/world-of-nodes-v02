# World of Nodes foundation roadmap

Owner-authorized 2026-09-22. This roadmap supersedes previous scope prohibitions
only as each dependency gate passes. The locked finite-food reference and every
published result remain preserved. A negative provisioning result is not a failed
software gate. No milestone requires efficiency or universal survival.

Implement → test → explain → pass gate → continue. On failure, stop expansion,
isolate the cause, run a bounded experiment, fix proven defects, and retest.
Technical coherence needs no additional approval. Property rights, cooperation,
monetary/political institutions, player powers, multiplayer fairness, core fantasy,
and irreversible abstraction choices require a project-owner decision.

Dependencies follow the listed foundation order. Geography testing accompanies
later systems, not just F1. Geography changes possibility, never causal law.
Research optimizers may inspect global truth; production policy may not. Production
physics, bounded policy, explicit institutions, and research instruments remain
separate. Borrow small established planning/task-allocation/queueing/flow ideas only
when evidence justifies them; no framework adoption by name.

Each completed milestone must link specification, parameters, tests, positive and
negative evidence, causal interpretation, revision and reproduction commands.
Keep old outputs immutable and new studies in distinct directories. The simulation
is authoritative: no silent creation of matter, knowledge, time, rights, labor,
transport, cooperation or productive capacity.
