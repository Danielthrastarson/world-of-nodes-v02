# World of Nodes foundation roadmap

Owner-authorized 2026-09-22. This roadmap supersedes previous scope prohibitions
only as each dependency gate passes. The locked finite-food reference and every
published result remain preserved. A negative provisioning result is not a failed
software gate. No milestone requires efficiency or universal survival.

Implement → test → explain → pass gate → continue. On failure, stop expansion,
isolate the cause, run a bounded experiment, fix proven defects, and retest.
Technical coherence needs no additional approval. Property rights, cooperation,
monetary/political institutions, player powers, multiplayer fairness, core fantasy,
and irreversible abstraction choices require a project-owner decision.

| Milestone | Status | Capability and gate |
|---|---|---|
| F0 Forecast / decision foundation | PASSED | Adopt tested mechanical corrections; isolate conditional meals; distinguish beliefs, goals, undertaking, atomic action. Covered contracts agree with execution; decisions use personal history only; interruption is explicit; invariants hold. Provisioning need not succeed. |
| F1 Generalized autonomous agent | PASSED | Same policy on line, branch, alternative routes, dead end, bottleneck, unequal sources. Test discovery, memory, physiology, routes, migration, FIFO and interruptions. No geography-specific policy, hidden resources or semantic IDs. |
| F2 Autonomous provisioning | PASSED | Trace demand through voluntary undertaking, acquisition, transport, consumption. Compare self-provision, migration, idle and physical controls. Demonstrate a plausible controlled chain or identify behavioral/institutional vs architecture cause of absence. |
| F3 Renewable production | PASSED | Located fertile land + actual labor + time → harvest. Account for natural transformation; finite initial stock no longer sole possible nourishment. Explain failures; do not guarantee sustainability. |
| F4 Dynamic labor | PASSED | Known shortages and opportunities alter voluntary production, gathering, carrying, rest, exploration. No worker ratios or omniscient job manager; measure churn. |
| F5 Capital before money | PASSED | One physical capital good, provisionally cart: material/labor cost, location, ownership, custody and carrying effect. Demonstrate short-term cost and context-dependent future benefit/harm. |
| F6 Construction / settlement | PASSED | Minimal causally necessary storage/sleep/infrastructure uses delivered materials, labor and time. Different geography creates different persistent spatial form. |
| F7 Emergent infrastructure | PASSED | Completed civilian travel creates paths; continued use maintains them and disuse reverses wear. Effective travel time changes route/traffic outcomes under unchanged capacity and FIFO. Engineered roads and staffed maintenance remain deferred. |
| F8 Two settlements | ACTIVE | Contrasting physical surplus/shortage, local ownership, existing communal transfers. Conserved flows or causal explanation of absence. No new exchange institution without an owner decision. |
| F9 Prices / money decision | NOT STARTED | Diagnose actual exchange/valuation/friction problem before comparing a common account/medium. Money never creates goods. Evidence for adoption OR deferral passes. Owner decides institution. |
| F10 Territory / authority | NOT STARTED | Practical communication, collection, protection, enforcement or administration depends on presence and geography. No arbitrary borders. Owner decides powers. |
| F11 Security / military economy | NOT STARTED | Mobilization redirects existing people, food, tools, transport and time. Measure civilian consequences; military strength depends on physical economy. |
| F12 Information network | NOT STARTED | Explicit physical messengers/travelers or constrained signals. Distinguish true from observed state; report delay changes decisions. No global knowledge. |
| F13 Kingdom vertical slice | NOT STARTED | Multiple settlements, economy, infrastructure, authority, information and security; one ruler decision yields unscripted, traceable second-order effects. Owner decides player powers. |
| F14 Target moment | NOT STARTED | Policy effects → households → institutional breakdown/coordination → actual gathering/travel toward castle. No spawn-rebellion shortcut. |
| F15 Rendering | NOT STARTED | World → observation → render snapshot → screen. Real identities/goods/roads/fields/units. Renderer never owns world state or time. |
| F16 Physical visual depth | NOT STARTED | Lighting, shadows, particles, fire, weather, limited physics where causally justified, with LOD. Low geometric complexity, high systemic complexity. |
| F17 Multiplayer foundation | NOT STARTED | Server-compatible kernel, stable IDs, explicit commands, reproducible compact events; small-player correctness before 50–100-player scale. No client-authoritative resources. |

Dependencies follow the listed foundation order. Geography testing accompanies
later systems, not just F1. Geography changes possibility, never causal law.
Research optimizers may inspect global truth; production policy may not. Production
physics, bounded policy, explicit institutions, and research instruments remain
separate. Borrow small established planning/task-allocation/queueing/flow ideas only
when evidence justifies them; no framework adoption by name.

Each completed milestone must link specification, parameters, tests, positive and
negative evidence, causal interpretation, revision and reproduction commands.
Keep old outputs immutable and new studies in distinct directories. The simulation
is authoritative: no silent creation of matter, knowledge, time, rights, labor,
transport, cooperation or productive capacity.

only; armies must later use the same geography, capacities and travel laws. No
military systems are authorized during F7.

F8 active: [registered two-settlement coordination study](TWO_SETTLEMENT_EXPERIMENT.md).
