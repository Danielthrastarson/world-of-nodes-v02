# F12 registered bounded information-transport study

Baseline `2b00dd9`. Preserve every earlier research file. Reports and delivered undertakings are opt-in; the historical default remains unchanged. This study defines no command authority, wages, compulsory labor, new ownership or monetary institution.

## Action and knowledge contract

A report captures one current local NodeView through an embodied living author's legitimate observation. It contains the immutable original author, observation node/time, and the same locally visible food quantities/ownership/custody/deadlines, incident edges, one-bank queues, request board and local presence facts already observable. It does not bundle unobserved remote information, private goals, social memories, true global authority, military rosters or future traffic.

Carriers keep personal copies. A living sender can share a known report only with a living person physically colocated at a node. Oral handoff follows the existing instantaneous local institutional-action convention; one selected action per decision opportunity, no global broadcast, material paper or magical inventory. Copies are information, not goods subject to material conservation. Original timestamps and authors survive forwarding. Receipt time is not observation time. Death does not transfer memory or notify absent people.

For this bounded truthful-report experiment, recipients may condition their existing forecasts on reported NodeViews. This is an explicit experimental acceptance rule, not a universal credibility model. Receipt provenance remains personally inspectable; report evidence updates spatial memory only when strictly newer than its existing observation. Equal-time direct evidence wins; duplicate handoff cannot freshen it. B2 trust is not silently converted into report credibility. No report is authoritative permission to act, claim goods or command people.

A research-assigned courier undertaking names one held report, recipient and rendezvous. It supplies no route or remote position. Common Person arbitration follows existing survival/care/work/service priorities. Routes use personal memories and actual FIFO. Sleep/eating pause an undertaking. Unknown route or predicted death may pause; local recipient absence cancels with an explicit reason. No automatic search, global tracking, replacement courier or return receipt. No autonomous messenger-recruitment claim.

## Gates and experiments

F12A deterministic contracts: nonlocal/dead/mid-edge rejection; exact original payload; no hidden truth leakage; newer direct information retained; out-of-order/repeated/relayed reports; no remote side effects; missing source memory cannot be invented; birth empty state; death no knowledge inheritance; deterministic action ordering and frozen personal-input decisions.

F12B live cases, 30 paired seeds each: short and long routes, congestion, unknown route, fatigue, critical hunger, absent recipient, courier death, stale/depleted source, paths on/off. Both arms contain identical physical people/goods/geography. One receives an explicitly seeded delivery undertaking; the unassigned control follows existing civilian policy. The difference includes information and displaced courier activity. All Persons remain embodied; deliberate initial recipient waiting in a mechanism stratum is disclosed and bounded, not an autonomous residence assumption. No physiology is frozen.

F12C matched-state receipt controls compare the same physical snapshot immediately before/after a legal local handoff, with identical personal RNG. Only the recipient's permitted information changes. Then unchanged autonomous decisions are inspected/executed. Include food availability that changes after observation, an older report arriving after newer direct observation, and identical truth with different personal reports. A physically feasible courier may fail to deliver; an accurately transmitted stale report may mislead. Neither is repaired by global truth.

Measure captures, carried/received/accepted/stale/duplicate reports, observation age and transit delay, decisions changed at matched state, courier travel/queue/sleep/food/starvation/death, recipient route/consumption/starvation, successful and missed rendezvous, and actual truth versus remembered truth strictly in the harness. Save causal observation→carriage→receipt→choice chains. Account for CPU/runtime and sparse report counts without claiming a large-population benchmark.

Pass when mechanically valid local information can physically reach another Person and change a later existing decision, while delay, staleness, absence, geography, physiology and death remain causally effective and historical regressions exact. This does not require beneficial information, spontaneous communication networks, command obedience or a kingdom gameplay proof.
